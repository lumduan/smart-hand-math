✋ Landmark capture — SmartHand Math PoC

Records raw MediaPipe HandLandmarker output (21 landmarks + the raw Left/Right label + score per hand) to a JSON file you drop into src/test/fixtures/hand-tracking/. Those captures then drive fingerMathLogic.real.test.ts, which verifies the gesture→number mapping on real hands and confirms the INVERT_HANDEDNESS default. Nothing is uploaded — the camera frame is processed in-page only.

Run over localhost (a secure context, required for camera access), e.g. from the repo root: python3 -m http.server 8080 then open http://localhost:8080/docs/plans/hand-tracking/PoC/capture.html.
